
# Triplet Sum in Array

## PATTERN: Sorting + Fix One + Two Pointers (3Sum Pattern)
→ **Trigger:** "when I see three numbers/triplet whose sum equals a target"

---

## BRUTE FORCE
→ **Idea:** Check every possible triplet using three nested loops.
→ **Crucial Snippet:**
```cpp
for(i)
    for(j)
        for(k)
```
→ **TC / SC:** `O(n³)` / `O(1)`

---

## OPTIMAL

→ **First instinct:** "I immediately sort the array, fix one element, and reduce the problem to a Two Sum using two pointers."

→ **Core idea:** Sort the array. Use a `for` loop to fix the first element (`arr[i]`). For each fixed element, initialize `left = i + 1` and `right = n - 1`. Compute `sum = arr[i] + arr[left] + arr[right]`. If the sum is too small, move `left++`; if too large, move `right--`; if equal, return `true`.

→ **Crucial Snippets:**
```cpp
sort(arr.begin(), arr.end());
```

```cpp
for(int i = 0; i < n - 2; i++)
```

```cpp
int left = i + 1;
int right = n - 1;
```

```cpp
int sum = arr[i] + arr[left] + arr[right];
```

```cpp
if(sum == target) return true;
else if(sum < target) left++;
else right--;
```

→ **TC / SC:** `O(n²)` / `O(1)`

---

## WATCH OUT FOR

→ Starting `left` from `0` instead of `i + 1` (the fixed element must not be reused).

---

## INTERVIEW FLOW (what I say out loud, in order)

1. Brute force is three nested loops → `O(n³)`.
2. Fix one element to reduce the problem to Two Sum.
3. Sort the array so Two Pointers become possible.
4. For each fixed element, move `left`/`right` based on the current sum.
5. Return `true` if found; otherwise continue and finally return `false`.
