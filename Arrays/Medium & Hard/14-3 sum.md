
## PROBLEM:
Given an array `arr[]` and a target, determine whether there exists **any triplet** `(arr[i], arr[j], arr[k])` such that:

`arr[i] + arr[j] + arr[k] == target`

Return **true** if such a triplet exists, otherwise return **false**.

---

## PATTERN:
**Sorting + Fix One Element + Two Pointers (3Sum Pattern)**

---

## WHY THIS PATTERN:

The problem asks for **3 numbers**.

Instead of searching for all three numbers together (which takes **O(n³)**):

- Fix one element.
- Now only two numbers remain to be found.

Finding two numbers in a sorted array is exactly the **Two Pointer** pattern.

So,

```text
3 Sum
   ↓
Fix One Element
   ↓
2 Sum
   ↓
Two Pointers
```

---

## CORE IDEA:

1. Sort the array.
2. Fix one element using a `for` loop.
3. Use two pointers to find the remaining two elements.
4. If:
   - Sum == Target → Return true.
   - Sum < Target → Move `left++`.
   - Sum > Target → Move `right--`.

---

## BRUTE FORCE:

### Idea

Check every possible triplet.

### Code

```cpp
for(int i=0;i<n;i++)
{
    for(int j=i+1;j<n;j++)
    {
        for(int k=j+1;k<n;k++)
        {
            if(arr[i]+arr[j]+arr[k]==target)
                return true;
        }
    }
}
return false;
```

### Dry Run

```
arr = [1,4,45,6,10,8]
target = 13

Check

(1,4,45)
(1,4,6)
(1,4,10)
(1,4,8) ✓
```

### Time Complexity

```
O(n³)
```

Three nested loops.

### Space Complexity

```
O(1)
```

## OPTIMAL APPROACH:

Instead of searching for all three numbers together:

- Sort the array.
- Fix one element.
- Find the remaining two elements using Two Pointers.

Think of it as:

```
Find 3 Numbers

↓

Fix One Number

↓

Find Remaining 2 Numbers
```

## COMMON MISTAKES:

### 1. Forgetting to sort

Two pointers require a sorted array.

---

### 2. Starting left from index 0

Wrong.

```cpp
left=i+1;
```

The fixed element cannot be reused.

---

### 3. Moving the wrong pointer

If

```
sum < target
```

Move

```cpp
left++;
```

Need a larger sum.

If

```
sum > target
```

Move

```cpp
right--;
```

Need a smaller sum.

---

### 4. Thinking the `for` loop performs the search

No.

The `for` loop only fixes one element.

The `while` loop searches for the remaining two.

---

### 5. Wrong loop limit

Instead of

```cpp
for(int i=0;i<n;i++)
```

Use

```cpp
for(int i=0;i<n-2;i++)
```

because at least two elements must remain after `i`.

## INTERVIEW FLOW:

> "The brute-force solution checks every triplet using three nested loops, which takes O(n³).

> We can optimize it by fixing one element. Once the first element is fixed, the problem becomes finding two numbers whose sum equals the remaining target.

> After sorting the array, I solve this Two Sum problem using two pointers. If the current sum is smaller than the target, I move the left pointer to increase the sum. If it's larger, I move the right pointer to decrease the sum. If the sum matches the target, I return true.

> If no pair is found for the current fixed element, I fix the next element and repeat.

> The overall complexity is O(n²) with O(1) extra space."

---

## TIME COMPLEXITY:

### Sorting

```
O(n log n)
```

### Outer Loop

```
O(n)
```

### Two Pointer Search

```
O(n)
```

Reason:

For one fixed element:

- `left` only moves right.
- `right` only moves left.

Neither pointer moves backward.

So one complete two-pointer search is linear.

### Total

```
O(n log n) + O(n × n)

=

O(n²)
```

Since O(n²) dominates O(n log n),

**Final Time Complexity = O(n²)**

## EDGE CASES:

- Array size exactly 3.
- No valid triplet.
- Multiple valid triplets.
- All elements same.
- Target = 0.
- Already sorted array.
- Reverse sorted array.
- Duplicate values (duplicates don't matter because we only need to return true/false).

# Clean C++ Code

```cpp
class Solution {
public:
    bool hasTripletSum(vector<int>& arr, int target) {

        sort(arr.begin(), arr.end());

        int n = arr.size();

        for(int i = 0; i < n - 2; i++) {

            int left = i + 1;
            int right = n - 1;

            while(left < right) {

                int sum = arr[i] + arr[left] + arr[right];

                if(sum == target)
                    return true;

                else if(sum < target)
                    left++;

                else
                    right--;
            }
        }

        return false;
    }
};
```
